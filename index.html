📖 Cara Main Ular Tangga

1. Kocok Dadu 🎲 — Klik tombol Kocok Dadu, pion jalan sesuai angka dadu.
2. Naik Tangga 🪜 — Kalau berhenti di bawah tangga, langsung naik ke atas!
3. Turun Ular 🐍 — Kalau berhenti di kepala ular, langsung turun ke ekornya!
4. Harus PAS 💯 — Untuk menang harus PAS di kotak 100. Kalau dadu lebih, kamu diam.
5. Dapat 6 = Main Lagi 🎉 — Kalau dadu 6, kamu dapat giliran lagi!
6. Mode Belajar 📚 — Kalau kena ular, jawab soal dulu. Benar = tidak turun, Salah = tetap turun.
